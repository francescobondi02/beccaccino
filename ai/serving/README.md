# serving

## Overview

FastAPI inference service for practice-game bots. The TypeScript backend sends
raw game state; the service rebuilds an equivalent `BeccaGame`, picks the
agent for the requested difficulty tier, and returns a briscola or card move.
`forte` and `esperto` load checksum-verified, weights-only inference
artifacts from `serving/models/`; `medio` has no weights. `facile` instead
loads a full training checkpoint (see the known limitation under Invariants).
Depends on
[`../becca_env/README.md`](../becca_env/README.md),
[`../evaluation/README.md`](../evaluation/README.md) (`NeuralAgent`,
`HeuristicAgent`), [`../inference/README.md`](../inference/README.md)
(`PIMCAgent`) and `training.checkpoint` ([`../training/README.md`](../training/README.md)).

## Interface

- `app.py`: FastAPI `app` with routes `POST /act` (bearer token required),
  `GET /tiers`, `GET /health`, `GET /version`, `GET /ready?tier=` (bearer
  token required); request/response models `ActRequest`
  (`state`, `seat`, `tier`, `temperature`, `expected_legal_cards`),
  `BriscolaMove`, `CardMove`; constants `BOT_SERVICE_TOKEN_ENV`,
  `PROMOTED_TIER = "forte"`, `MAX_TEMPERATURE = 2.0`; `lifespan` startup hook
  (`[app.py:act]`, `[app.py:lifespan]`).
  - `GET /health` is public but not static: it builds (or reuses) the `forte`
    agent and returns 503 when it cannot (`[app.py:health]`).
  - `/ready` returns 422 for an unknown tier; `/ready` and `/health` return
    503 for any other agent-build failure (`[app.py:_readiness_response]`).
  - Responses are `BriscolaMove` (`kind: "briscola"`, `suit`) or `CardMove`
    (`kind: "card"`, `suit`, `value`, `signal`) (`[app.py:_move_response]`).
- `state_adapter.py`: `state_dict_to_game(state)`,
  `game_to_state_dict(game, seat)`, `StateAdapterError(ValueError)`,
  constants `NUM_SEATS`, `TRICKS_PER_ROUND`, `RAW_PER_POINT`
  (`[state_adapter.py:state_dict_to_game]`). The `state` wire format:
  - `phase`: `"choose_briscola"` or `"play_card"`.
  - `briscola`: suit string, or `null` before it is chosen.
  - `round_number` (1-based), `caller_seat`, `trick_starter`, `win_points`.
  - `hands`: `{seat: [{suit, value}, ...]}` for all four seats.
  - `completed_tricks`: `[{cards: [{seat, suit, value}, ...], signal,
    signal_seat}]` for the current round.
  - `current_trick`: `[{seat, suit, value}, ...]` in play order;
    `current_signal`: the current leader's signal or `null`.
  - `total_scores`: `{"0": raw, "1": raw}` cumulative raw points.
  - `cricca`: optional, copied into the round without validation.
  - `game_to_state_dict` also emits `acting_seat`, which
    `state_dict_to_game` ignores (`[state_adapter.py:game_to_state_dict]`).
- `tiers.py`: `Tier`, `TIERS` (`facile`, `medio`, `forte`, `esperto`),
  `available_tiers()`, `get_agent(tier_name, temperature)`,
  `UnknownTierError`, `TierUnavailableError`, `PIMC_DETERMINIZATIONS = 10`,
  `PIMC_ROLLOUT_POLICY = "heuristic"` (`[tiers.py:TIERS]`).
- `artifact.py`: `export_inference_artifact(source_path, destination_path,
  selection_protocol=...)`, `load_inference_artifact(path, map_location)`,
  `InferenceArtifactError`, `INFERENCE_ARTIFACT_FORMAT = 1`,
  `INFERENCE_ARTIFACT_KEYS`, `SOURCE_KEYS`
  (`[artifact.py:load_inference_artifact]`).
- `fixtures/bot_states.json`: committed cross-language observation fixtures
  (generated by `scripts/gen_bot_fixtures.py`, see
  [`../scripts/README.md`](../scripts/README.md)).

## Invariants

- Startup fails unless `BOT_SERVICE_TOKEN` is set and non-empty and the
  `forte` agent loads (`[app.py:lifespan]`, `[app.py:_configured_bot_token]`).
- `/act` and `/ready` require `Authorization: Bearer <token>` compared with
  `secrets.compare_digest`; failures return 401 (`[app.py:_require_bot_token]`).
- `/act` checks run in this order (`[app.py:act]`,
  `[app.py:_reject_on_legal_move_disagreement]`):
  1. Malformed state: any `KeyError`, `TypeError`, `ValueError` (including
     `StateAdapterError`) or `AttributeError` from `state_dict_to_game`
     returns 422 "malformed game state".
  2. 409 when `seat` is not the current seat, then 409 when
     `expected_legal_cards` differs from the engine's legal cards.
  3. Tier lookup: 422 for an unknown tier; 503 (`TierUnavailableError`) when
     the tier's file is missing or fails integrity checks
     (`InferenceArtifactError` or `CheckpointIntegrityError`)
     (`[tiers.py:_load_net]`).

  Because the seat checks run first, an unknown tier sent with the wrong seat
  gets 409, not 422. Other load errors, such as an unreadable `facile`
  checkpoint without a `.sha256` sidecar, still return 500.
- `seat` is in `0..3` and `temperature` in `[0, 2]` (`[app.py:ActRequest]`).
- Cards, suits and signals cross the wire as enum strings, never indices,
  because Python and Prisma suit orders differ
  (`[state_adapter.py]` module docstring, `[state_adapter.py:_card]`).
- Cumulative `total_scores` are raw points (`points * 3 + figures`)
  (`[state_adapter.py:RAW_PER_POINT]`).
- Only `choose_briscola` and `play_card` phases are accepted; all four hands
  are required; at most 10 completed tricks of exactly 4 cards; the current
  trick has fewer than 4 cards; completed-trick winners are recomputed, never
  trusted (`[state_adapter.py:state_dict_to_game]`,
  `[state_adapter.py:_trick_record]`). The rebuilt game is not resumable.
- `esperto` must use PIMC with heuristic rollouts, never net rollouts
  (`[tiers.py:PIMC_ROLLOUT_POLICY]`); `medio` is the heuristic with no weights
  (`[tiers.py:_build_agent]`). `temperature` only affects `facile` and
  `forte`; `medio` and `esperto` ignore it, but the agent cache is still keyed
  by `(tier, temperature)` (`[tiers.py:get_agent]`).
- `available_tiers()` and `GET /tiers` list only tiers whose file exists in
  this deployment (`[tiers.py:available_tiers]`).
- Known limitation: `facile` loads
  `checkpoints/kaggle-runb/checkpoints/runB_bc.pt`, a full training checkpoint,
  through `training.checkpoint.load_checkpoint`. That loader treats the
  `.sha256` sidecar as optional and unpickles with `weights_only=False`
  (`[tiers.py:TIERS]`, `[tiers.py:_load_net]`). The file is git-ignored and
  `.dockerignore` excludes `checkpoints`, so the deployment image cannot serve
  `facile`. The decision on this tier is pending.
- Inference artifacts must have a valid 64-hex `.sha256` sidecar matching the
  file, exactly the expected keys, format 1, and load with
  `torch.load(..., weights_only=True)` (`[artifact.py:load_inference_artifact]`,
  `[artifact.py:_verify_checksum]`).

## Side Effects

- Reads `BOT_SERVICE_TOKEN`, `RENDER_GIT_COMMIT` and `GIT_COMMIT_SHA`
  environment variables (`[app.py:_configured_bot_token]`, `[app.py:version]`).
- Loads checkpoints and inference artifacts from disk relative to the `ai/`
  root and caches built agents in process memory keyed by
  `(tier, temperature)` (`[tiers.py:_agent_cache]`, `[tiers.py:_load_net]`).
- `export_inference_artifact` writes the artifact and its `.sha256` sidecar
  atomically (temp file, `fsync`, `chmod 0o644`, `os.replace`)
  (`[artifact.py:_atomic_save]`, `[artifact.py:_atomic_write_text]`).
- Serves HTTP when run under an ASGI server such as uvicorn.
